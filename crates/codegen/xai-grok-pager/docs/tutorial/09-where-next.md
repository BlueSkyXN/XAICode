# Where to Go Next

You know enough to be productive. When you want more:

## Built-in help

- **`/help`** or **`Ctrl+P`** — every command, shortcut, and skill, searchable.
- **`/docs`** — the full local How-to Guides inside the TUI. Covers sessions,
  headless mode, subagents, sandboxing,
  memory, and much more.
- **Ask Xaicode itself** — it can read its local user guide and set itself up.
  Try: "How do I run you in CI?" or "add an MCP server for GitHub".

## Good habits

- Sessions save automatically. Resume the latest with `xaicode -c`, or pick
  one with `/resume` (`Ctrl+S`).
- Long session getting slow? `/compact` frees context; `/context` shows
  where it's going.
- Automate anything: `xaicode -p "summarize new TODOs" --output-format json`
  runs headless — great for scripts and CI.
- Updates are handled by your normal package/release workflow; see
  `/release-notes` for local release notes.
- Something feels off? Capture local logs and report it through your project
  issue workflow; hosted feedback is disabled.
